Multi-Tier Content Access Showcase

All users sign in through the same login page using the authlab Keycloak realm, but the page dynamically unlocks content and editing capabilities based on their Keycloak role:

📖
Reader Access (viewer — e.g. alice)

Sees only Reader Content (Documentation, Status Bulletins, Knowledge Base) in strict Read-Only mode. Developer and Admin sections are locked.

💻
Developer Access (developer — e.g. dev)

Sees both Reader Content AND Developer Content (Feature Flags, CI/CD Configs, Webhooks) and can edit & create items in both tiers.

🛡️
Admin Access (admin — e.g. bob)

Unlocks ALL 3 Tiers (Reader + Developer + Admin Security Vault & IAM Governance) with full Create, Edit, and Delete privileges.
